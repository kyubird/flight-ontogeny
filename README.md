# flight-ontogeny

[![Actions Status][actions-badge]][actions-link]
[![PyPI version][pypi-version]][pypi-link]
[![PyPI platforms][pypi-platforms]][pypi-link]

Codes for analysing how zebra finch fledglings develop their flight.

## Installation

```bash
python -m pip install flight_ontogeny
```

From source:
```bash
git clone https://github.com/kyubird/flight-ontogeny
cd flight-ontogeny
python -m pip install .
```
